# Wireframe Spec

## 목적

이 프로젝트는 와이어프레임 작업을 위한 React 화면 구현 환경이다.
목표는 복잡한 기능 완성이 아니라, 화면을 빠르게 출력하고 디자인 구조를 검증하는 것이다.

## 우선순위

1. 화면 출력이 최우선이다.
2. 디자인 구현을 가장 중요하게 본다.
3. 가능한 한 동일한 컴포넌트를 반복 사용한다.
4. 복잡한 연산보다 단순한 구현을 우선한다.
5. 기본 인터랙션은 버튼 클릭, 페이지 이동, 탭 전환처럼 확인 가능한 동작으로 만든다.

## 구현 원칙

- 화면은 최대한 간결하게 구성한다.
- 컴포넌트는 재사용 가능한 단위로 나누되, 과한 추상화는 피한다.
- 데이터 처리, 상태 관리, 계산 로직은 최소화한다.
- 임시 데이터는 화면 검증에 필요한 만큼만 둔다.
- 사용자가 클릭할 수 있는 요소는 실제로 동작하게 만든다.
- 스타일은 화면 유사도와 일관성을 기준으로 판단한다.

## 완료 기준

- `npm run dev`에서 화면이 정상 출력된다.
- 주요 버튼이나 링크가 기본 이동/전환 동작을 수행한다.
- 반복 UI는 같은 컴포넌트를 사용한다.
- 불필요하게 복잡한 로직이나 라이브러리를 추가하지 않는다.
